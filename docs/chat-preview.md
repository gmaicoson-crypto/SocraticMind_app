# 本地聊天体验版

2026-10-28，当前工作按用户要求收口为可体验 App 和聊天链路。用户随后明确先不配置模型，因此本轮完成安装包、聊天界面验证及提交后停止开发，不再继续学习页面等功能。

## 当前可体验范围

Android Debug APK 和 iOS 模拟器应用已构建，可连接本机后端完成注册、登录和进入聊天页面。应用保留双端原生实现，后端、数据和接口均在本仓库维护。

当前本地环境尚未配置模型。聊天页面可打开和输入，但不能把这当作已经得到真实 AI 回复；模型目录不可用、发送失败均不能作为聊天成功证据。最终仍需验证：发送问题 → 显示真实回复 → 结束生成 → 重新打开会话后消息保留。

## 打开应用

安装产物保存在不纳入 Git 的 `local-data/deliverables/`：

- `SocraticMind-0.1.0-debug.apk`：Android 官方模拟器使用，默认访问 `http://10.0.2.2:8765/`。
- `SocraticMind-Simulator.app`：本机 Apple Silicon iOS 模拟器使用，默认访问 `http://127.0.0.1:8765/`，不是 iPhone 安装包。

本轮使用 `Pixel_API_36` 和 `SocraticMind-Auth-20261023` 模拟器。应用已安装；本地后端运行时可直接从模拟器桌面打开 SocraticMind。定向验证使用合成账号，不涉及真实用户数据。当前包未验证真机，不应把模拟器专用地址当作手机可访问地址。

后端没有运行时，在仓库根目录执行：

```bash
.venv/bin/python -m scripts.dev.local_backend run
```

已有服务时不要重复启动；使用 `status` 查询。数据保存在 `local-data/backend/`，正常停止和重启不会清空数据。详细配置和验证码读取方式见 [本地后端说明](local-development.md)。

## 接通真实模型

在本机 `local-data/backend/.env` 中填写所选服务商提供的配置，不能将密钥提交到 Git 或发到聊天中：

```dotenv
LLM_API_KEY=填写本机密钥
LLM_BASE_URL=填写服务商兼容接口地址
LLM_MODEL=填写实际可用模型名称
```

也可以使用 [后端配置样例](../backend/.env.example)中的 `LLM_MODELS` 多模型格式。不要同时保留冲突的旧配置。配置后正常停止并重启本地后端，再在 App 中刷新模型、新建对话。运行中的环境有互斥锁，`doctor` 应在停止后执行；它只检查配置，不保证模型服务可用。

当前停止开发，不因原始总计划继续扩展功能。以后用户明确要求接入模型时，再完成真实回复和会话恢复验收；现在交付状态为“应用可打开，真实聊天暂缓验收”。

# 内测 V1 产品范围与功能验收

更新：2026-10-22。适用 Android、iOS 和本仓库 backend；用户已确认面向中国大陆的可持续内测交付。本表为最终 V1 范围，阶段列仅表示实现顺序，不表示后期能力可省略。当前全部功能待实现 / 待验证。

来源为[源项目固定版本审查](reference-audit.md)。已有后端能力复用并验证；原生 UI、移动生命周期和本地存储需要分别实现。运行支持和反馈是本项目交付需要，不宣称上游已具备。

## 使用者和核心路径

首版服务希望围绕主题持续学习的中文用户，手机为主要设备；不增加教师管理、多租户组织或支付体系。若以后改变目标人群和收费方式，另行规划对应账号、数据和分发能力。

建议保留三项主导航「学习 / 对话 / 我的」：学习首页包含今日计划和主题入口；主题进入图谱与节点学习；对话负责普通聊天和历史；我的包含统计、记忆、模型设置、资料和本地笔记入口。笔记也可从学习 / 对话上下文进入，避免重复保存入口和状态。

关键流程：注册 / 登录 → 创建主题 → 回答目标及诊断 → 确认计划 → 查看今日任务 / 图谱 → 进入节点对话 → 评估或按服务端规则标记掌握 → 记录进度 → 次日继续。普通对话是独立入口，消息展示、输入、附件与来源组件在平台内共用。

| P11 资料与账号删除 | 资料、头像、注销 / 删除账号、清理本地与远端数据流程 | 删除前解释范围；验证后端关联数据和附件清理；旧凭证不能继续使用；失败不假报成功 | M2 基础，M4 完整 |
| P12 模型设置 | 默认模型选择、源项目已有用户模型配置管理 | 至少一个模型无需用户自行配置即可用于约定内测；配置校验与错误可见；用户密钥不回显、不持久缓存；服务端保存按源策略核查 | M2 选择，M4 管理 |
| P13 进度与成就 | 打卡、统计、热力图、成就和相关明细 | 与后端统计口径一致；时区边界、无记录、掌握撤销后的状态可解释 | M4 |
| P14 本地笔记与画布 | Markdown 编辑预览 / 保存 / 导出，原生画布工具和 PNG 分享 | 参考源工具清单逐项映射；重启可恢复；账号 / 主题隔离；导出可打开；未保存内容有反馈 | M4 |
| P15 移动体验 | 深浅主题、键盘避让、导航返回、大字体、读屏、加载 / 空 / 错误状态 | 三条主路径在两端实际设备可操作；不只靠颜色表示节点状态；离线状态明确；未完成入口不冒充功能 | M1—M4 |
| P16 内测支持 | 版本信息、安装升级说明、反馈入口、服务不可用提示、数据使用与删除说明 | 用户能说明自己版本并反馈；反馈不默认上传聊天；维护人可关联脱敏请求 ID 定位；安装及更新路径真实可用 | M4—M5 |

最终候选版应逐项记录 Android、iOS、backend 的状态和证据。P14 本地操作没有后端实现项，应明确标记“不适用及理由”，不能当作后端测试已通过。对于“源项目已有动作”，M0-01 要展开具体控件 / 动作清单，确认没有漏迁；未核对清单前不能关闭该项。

## 明确限制与后续范围

以下是 V1 的边界。变更它们需要更新任务和验收，不通过模糊承诺留到最后。

| 内容 | V1 处理 | 后续扩展条件 |
| --- | --- | --- |
| Web 3D 图谱效果 | 原生 2D + 节点列表，保留学习语义，不复刻全部 Three.js 动效 | 验证有实际使用价值后独立评估 |
| Markdown 笔记 / 画布同步 | 本地持久化、明确“此设备保存”；提供导出 | 新增后端协议、冲突处理和数据迁移 |
| 离线 AI / 完整离线学习 | 只提供已缓存内容和本地编辑；AI、评估等联网操作不静默排队重放 | 另行定义离线任务与同步状态机 |
| 后台持续生成 | 不保证手机后台持续收流，返回后从后端状态与历史恢复 | 按平台能力单独验证，不以保活绕过限制 |
| 扫描文档 OCR | 不承诺源能力之外的 OCR；不支持的文件有清楚反馈 | 评估识别服务、成本与数据流 |
| 旧 Web 用户 / 数据 | 默认独立库和账号数据；不会自动迁移或同步 | 用户提出迁移目标后另做版本及数据方案 |
| 平板专用布局、推送、语音、社交和支付 | 不纳入 V1；不设置假入口 | 明确需求、预算和接口后规划 |
| App Store / Android 商店公开上架 | 本次不要求公开发布；按实际内测分发路径准备必需材料 | 后续独立确定渠道及提交要求 |

退出或删除账号前要明确告知本地笔记、草稿和画布的清理行为，并提供适用的导出路径；不能用“重新登录后仍能恢复”描述只存在本地且已清理的数据。

## 共用验收场景

以下是跨功能业务验收，功能改动按影响选择对应场景。不是日常 CI 全量测试命令。设备行为需要取得对应构建 / 运行安排后验证。

| 场景 | 前提与操作 | 预期结果 | 范围 |
| --- | --- | --- | --- |
| J01 新用户开始学习 | 注册，建主题，完成引导并确认计划，进入第一个可学习节点 | 主题唯一；计划和图谱一致；可进入节点问答 | P01、P04—P06 |
| J02 完成并继续 | 节点对话，评估 / 掌握，退出，另一天或另一端重新登录 | 进度由服务端恢复；没有重复完成；当地日期显示正确 | P01、P05—P08、P13 |
| J03 中断与取消 | 流中断网、前后台切换、结束进程，再恢复；另测显式停止及其失败 | 不产生第二次生成；状态和历史一致；停止与断网语义区分 | P02、P03 |
| J04 会话异常 | 凭证失效、重复点击、模型超时、服务拒绝和维护中 | 不假报成功；用户能恢复操作；草稿与服务器结果不串用 | P01—P03、P12、P16 |
| J05 文件学习 | 选择各支持类型、上传、等待解析、提问、打开来源；另测超限和坏文件 | 能解释受支持内容；不支持 / 失败有反馈；不绕过鉴权 | P03、P09、P10 |
| J06 用户隔离 | A 创建对话 / 笔记 / 附件，退出登录 B；再删除测试账号 | B 无法看到或读取 A 的私有内容；清理范围和凭证行为符合设计 | P01、P08、P10、P11、P14 |
| J07 本地创作 | 编辑笔记和画布，切后台、重启、导出；取消系统分享 | 内容持久化、导出可打开；取消不破坏原件；说明本地范围 | P14、P15 |
| J08 设备体验 | 长聊天、大图、键盘、系统返回、大字体 / 读屏、深浅主题 | 核心流程可完成；不存在遮挡或只有颜色的操作提示 | P02、P06、P15 |
| J09 升级与服务恢复 | 从前一内测版升级；后端升级及隔离恢复演练；旧版继续访问 | 数据不丢失；支持期内旧客户端仍可用；异常有处置路径 | 所有受升级影响项、P16 |

普通 / 节点对话必须共用组件且分别验收语义。学习场景先用固定假模型验证状态规则，再以脱敏内容在约定模型上少量人工检查教学质量；不把模型随机输出设成自动测试的固定文案，也不让常规 CI 产生模型费用。

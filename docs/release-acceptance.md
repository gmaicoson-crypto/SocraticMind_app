# 本地成品与运行交接验收

更新：2026-10-22。用户已确认当前本地开发、不上线，没有 Apple 开发者账号。本文件据此修订原外部内测方案：云部署、TestFlight、付费开发者账号和邀请外部测试员不作为本次前置条件。完整 P01—P16 功能与双端质量要求保留；实际完成证据见 [实施状态](execution-status.md)。

## 完成条件与证据

每份候选版记录绑定源版本、两端版本号、backend 版本、Alembic revision、契约摘要、运行方式、设备 / 模拟器、具体用例、时间与结果。源码尚未提交时记录文件摘要和工作区状态，不虚构提交号。报告不包含密码、Token、模型密钥、真实聊天或附件。

| 关口 | 必须满足 | 缺口处理 |
| --- | --- | --- |
| 功能 | [P01—P16](product-scope.md)和 J01—J09 有双端及适用后端证据 | 必交项留在实现 / 待验证，不能以候选版冻结隐藏 |
| 自动质量 | 相关格式、lint、行数、依赖、契约和定向测试通过 | 修复后重跑相关项，不放宽规则 |
| 原生行为 | 核心流程、键盘、权限、生命周期、文件和性能有对应平台证据 | 主机测试不能抵扣；区分模拟器和真机结果 |
| 运行 / 安装 | 用户能按本地指引启动并完成学习；实际安装后可升级且保留数据 | 未执行构建或无设备时明确未验证，不宣称可安装成品 |
| 后端与数据 | 本地可重启、数据持久化、备份可恢复、错误可诊断 | 临时测试数据库不能代替持久开发服务 |
| 交接 | 工具与依赖可复现、限制与维护步骤明确 | 缺工具 / 模型 / 签名时写清影响与恢复步骤 |

证据随阶段累积；最终只补待验项、受候选变化影响的回归和安装冒烟，不执行无范围的全量测试。GitHub 未连通时可记录真实本地检查，不能声称远端 CI 已运行；远端接入仍为后续协作待办。

## 缺陷规则

- 阻断：主流程崩溃、跨账号访问、数据丢失、重复生成失控、应用无法启动 / 安装、服务不可恢复。必须解决。
- 严重：必交功能无法完成或必须人工改库继续。必须修复并验证相关功能。
- 一般：不阻断任务且有可用替代路径的体验问题。记录影响、临时处理、归属和后续工作。

候选变化涉及协议或存储时，重新验证对应兼容 / 升级路径。不以 mock、另一平台结果或“没有反馈”替代验收。

## 系统、设备与性能

已确认最低 Android 8.0 / API 26、iOS 17。按实际资源登记最低系统和当前主力系统覆盖；模拟器补系统覆盖，真机记录权限、文件、后台及实际性能。没有相应设备时保留缺口，不自动降低最低系统或假定已通过。

Android 设备测试若生成 APK，必须等待明确构建要求。iOS 模拟器应用验证会编译应用宿主，独立安排；纯 Swift 包测试只验证核心逻辑，不代表 SwiftUI 应用已经运行。IPA / archive 仍独立触发。

| 场景 | 初始预算 / 方法 | 关联 |
| --- | --- | --- |
| 冷启动 | 固定设备、配置、样本数；本地首屏可交互目标 2 秒内，网络等待另计 | P15 |
| 长对话 | 500 条历史、20 KB 流消息；分页、稳定 ID、约 50—100 ms 合并活动消息刷新 | P02、P03 |
| 图谱 | 100 节点目标接近 60 fps；300 节点记录掉帧、内存与列表降级 | P06 |
| 生命周期 | 连续 20 次进出页面；无重复订阅、消息及持续内存增长 | P03、P15 |
| 文件 | 能力边界、流式 IO、图片下采样、取消和临时文件清理 | P10、P14 |
| 可访问性 | 大字体、读屏焦点、语义标签、非颜色提示、返回和键盘 | P15 |

预算是待测目标，不能写成当前指标。AI 首事件和服务端延迟单独记录。调整预算需保留理由与原测量结果，不删除失败指标。

## 本地服务与真实依赖

| 环境 | 数据 / 使用方式 |
| --- | --- |
| 单元 / 契约测试 | 合成数据、假模型、临时文件；只运行相关用例 |
| 隔离 MySQL 验证 | 脚本自有临时实例，禁用网络监听，结束清理；不连接既有库 |
| 持久本地开发 | 独立开发库、固定密钥、持久附件、明确启动停止与备份目录；不由测试清理 |

M1-06 实现本地运行入口，明确 Python / MySQL、依赖锁、迁移、worker、健康检查和配置位置。只允许 App 开发配置访问受控本地地址；发布配置不继承任意明文网络放行。模拟器回环与真机局域网地址分开说明。

至少一个真实可用模型需在实际学习流程验证。搜索、邮件与附件解析按功能逐项小样联调；失败有明确状态，不能伪造成功。SMTP 控制台验证码只用于个人本地调试。当前没有模型配置，不从旧项目读取密钥，也不自动进行付费模型压力测试。

本地并发和附件额度根据实测限制；优先复用源配额 / worker 机制。记录超时、取消、任务积压、磁盘、费用与错误。没有云服务不意味着可以忽略数据保护和资源消耗。

## 数据与恢复

备份包含数据库、附件及恢复所需的配置 / 解密密钥，记录一致性时间点；真实密钥不进 Git。笔记和画布属于客户端本地数据，通过导出另行保存，不能误称后端备份已包含。

恢复演练在新建隔离位置执行：备份 → 还原数据库 / 附件 / 必要配置 → 启动相应版本 → 核对账号、对话、图谱及附件 → 记录耗时和损失窗口。不得覆盖正在使用的开发数据。

迁移采用先扩展、兼容旧客户端、再收缩的顺序；不可逆迁移不依赖盲目 downgrade。应用升级验证客户端缓存 / 草稿 / 笔记迁移；后端保留当前与前一已交付客户端契约的初始兼容策略。必要的回退仅使用兼容当前 schema 的代码。

日志只保留请求 ID、版本、错误码、耗时和任务状态等脱敏信息。账号删除覆盖活跃数据、附件和凭证，说明备份保留与恢复后删除标记。用户模型地址访问范围在 M4-03 核查，密钥不回显或缓存到客户端。

## 本地应用验证与签名

| 平台 | 当前方式 | 实际验收限制 |
| --- | --- | --- |
| Android | Android Studio 工程；明确要求后构建开发 APK / 进行设备验证 | 包名、签名、版本连续；验证安装 / 升级，不要求商店或 AAB |
| iOS | Xcode 工程、Swift 包主机测试；应用模拟器验证独立安排 | 模拟器不需要付费会员；真机按 Apple Account / Personal Team 实际条件设置与验证 |

Apple 允许免费 Apple Account 用于 Xcode 开发；未加入付费项目时属于 Personal Team，相关 App ID、设备注册和 provisioning 有限制，配置描述文件 7 天后需重新生成，设备应用可能要重装。因此本地开发不要求购买会员，也不能承诺一次个人签名永久有效。[Apple 账号说明](https://developer.apple.com/help/account/basics/about-your-developer-account)

不在源码写入个人 Team、证书或密码。用户在需要真机时自行登录 Xcode；不要求通过聊天提供账号凭据。未明确构建要求前保留相应待验项，继续推进独立的源码与主机测试。
